# `@repo/shared`

Shared brand configuration, domain constants, language metadata, room categories, and WebSocket event contracts used across `@repo/web` and `@repo/api`.

## Exports

- `BRAND_CONFIG`, `APP_NAME`, `APP_SHORT_NAME`, `APP_VERSION`, `BOT_NAME` *(central place to update the temporary project name)*
- `STORAGE_KEYS`
- `ROOM_CATEGORIES`
- `SUPPORTED_LANGUAGES`
- `WS_EVENTS`
